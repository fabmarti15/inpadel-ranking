📋 Subir Fecha

Copia los resultados del último americano desde el Excel y pégalos aquí. La página calcula los puntos y actualiza el ranking sola.

1. Abre github.com/settings/personal-access-tokens → Generate new token (fine-grained).
2. En Repository access elige Only select repositories → inpadel-ranking.
3. En Permissions → Repository → Contents elige Read and write.
4. Genera el token (empieza con github_pat_), cópialo y pégalo aquí. Solo lo pegas una vez.
